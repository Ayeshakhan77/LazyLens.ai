# LazyLens AI

**Turn your CSV data into clear insights with AI-assisted analysis.**

LazyLens AI is a data analysis application designed to help users explore datasets, understand data quality, visualize patterns, and generate useful insights without manually performing every analysis step.

## Overview

Working with raw datasets can be time-consuming, especially for beginners, students, and small businesses. LazyLens AI aims to simplify this process by bringing data exploration and visualization into one interface.

## Features

- **CSV Upload:** Upload a dataset for analysis.
- **Data Preview:** Explore rows, columns, and dataset structure.
- **Data Quality Analysis:** Identify missing values, duplicates, and potential data issues.
- **Statistical Summary:** Examine descriptive statistics and key data characteristics.
- **Data Visualization:** Present patterns and trends through charts.
- **AI-Assisted Insights:** Generate explanations and insights from analyzed data, where the AI model is configured and available.
- **Reports:** Present analysis results in a format that is easier to understand and share.

## How It Works

1. Upload a CSV dataset.
2. Inspect the dataset and its structure.
3. Analyze data quality and calculate statistical summaries.
4. Explore charts and visual patterns.
5. Review AI-generated insights, if AI inference is available.
6. Export or share the analysis if supported by the application.
